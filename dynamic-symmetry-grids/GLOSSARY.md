## One-sentence idea

**Dynamic symmetry** = pick a lawful rectangle for your crop, then use a built-in **armature** (diagonals + reciprocals + eyes) so every important thing has a *related* place—unity, rhythm, and movement instead of random thirds habit.

## Core definitions (skim table)

| Term | Definition (plain English) | Why it matters |
|------|----------------------------|----------------|
| **Dynamic symmetry (DS)** | Composition system (Hambidge / Glover) that builds related lines inside a rectangle so the design has life, order, and variety. | Better default than “stick it on the thirds.” |
| **Armature** | The full set of construction lines inside the frame (diagonals, reciprocals, H/V through eyes, optional MAD). | The map you place subjects and type on. |
| **Root rectangle** | A family of rectangles grown from a **square** by swinging diagonals outward: root 2, root 3, root 4… | Matches common crops (e.g. root 3 ≈ 16:9). |
| **Phi (φ) rectangle** | Ratio ≈ **1.618** (“golden” family). Also called the rectangle of **whirling squares**. | Natural/organic proportion; near 1.5 stills. |
| **Root-phi** | Ratio ≈ **1.272**. | Near 11×14 / letter-ish frames. |
| **1.5 rectangle** | A square plus half a square; ratio **1.5**. | Classic 4×6 / 2:3 / 24×36 stills. |
| **Mother rectangle** | The outer canvas you are designing in. | Everything else subdivides *inside* it. |
| **Basic armature** | **2 main diagonals** + **4 reciprocals** + optional **horizontals/verticals through eyes**. | Enough for most thumbs and heroes. |
| **Diagonal (main)** | Corner-to-corner line across the mother rectangle. | Primary energy lines; great for subject tilt and gaze. |
| **Baroque diagonal / sinister diagonal** | Names for the two main diagonals (so you can talk about *which* one you used). | Communication; vary which diagonal carries the subject. |
| **Reciprocal** | A line from a corner that meets a main diagonal at **90°**. It carves a smaller, related rectangle out of the mother. | Creates *related* margins and secondary zones—not random padding. |
| **Eye** | Any **intersection** where armature lines meet. | Best seats for focal points; also spawn points for new lines. |
| **Polar point** | A special eye: where a reciprocal meets a main diagonal at 90°. | Generates the horizontal/vertical lines of the basic armature; geometric “hinge.” |
| **Theme** | How the mother rectangle is **subdivided** into smaller related areas (Hambidge’s term for area divisions). | Rhythm across a page or multi-beat frame. |
| **Theme of 2 / 3 / 4 / 8…** | Divide the mother into 2, 3, 4, 8… equal related modules (often along verticals from the armature). | Panels, sections, repeated modules, “theme-of-4x” grid files. |
| **NDT (numeric dynamic theme)** | Themes defined by clean equal divisions of the basic armature (easy vertical counts of smaller roots). | Practical “how many modules” language. |
| **MAD (major area divisions)** | Take the basic armature and **shrink it into the main sub-areas** of the mother (often like a theme of two, with lighter lines under the dark basic armature). | Multi-zone frames: face + title + prop with hierarchy. |
| **Overlapping roots** | Sliding one root rectangle over another along **eye increments** so the outer canvas still holds equal related roots. | Custom sizes that stay “lawful,” not sloppy. |
| **Compound roots** | Combining more than one root system in one design. | Complex multi-zone compositions. |
| **Whirling squares** | Phi construction: squares spiral proportionally around polar geometry. | Phi grids; organic growth feel. |
| **Rebated square** | Square “cut back” / related square construction inside a root (seen in some grid filenames). | Extra structure for centers and nested squares. |
| **Gamut / echo** | Repeating a diagonal or angle elsewhere so shapes **rhyme**. | Unity—secondary elements support the main without cloning it. |
| **Crop integrity** | Final crop ratio must **match** the rectangle you composed in. Changing ratio after the fact **breaks** the armature. | Always compose for the real delivery size (16:9, 9:16, etc.). |
| **Rule of thirds (ROT)** | Generic 3×3 grid; popular but **predictable**. | DS allows more variety; avoid parking every subject on the same thirds hotspots. |
| **Better-than-thirds variety** | Intentionally use different diagonals, horizons, themes, and negative-space extremes so work doesn’t all look the same. | Anti-repetition with structure still intact. |
| **Breathing room / gaze direction** | Space in front of a face/gaze; balance of mass vs empty. | Keep subjects from feeling cramped even on strong lines. |
| **Diagonal gauge** | Overlay tool (`Diagonal Gauge*.jpg`) to discover which diagonal family an existing image fits. | Analysis before picking a PNG grid. |

## Root ratios (cheat sheet)

Grown from a square: swing diagonal → root 2 → root 3 → …

| Name | Ratio (long ÷ short) | Everyday cousin |
|------|----------------------|-----------------|
| Root 2 | ≈ 1.414 | Near 5×7 |
| Root 3 | ≈ 1.732 | Near **16:9** YouTube / cinema |
| Root 4 | 2.0 exactly | Double square |
| Root 5 | ≈ 2.236 | Near 21:9 ultra-wide |
| Root 6 | ≈ 2.449 | Wide cinematic graphic |
| Root 7 | ≈ 2.646 | Panorama / very wide |
| Phi (φ) | ≈ 1.618 | Near 1.5; whirling squares |
| Root-phi | ≈ 1.272 | Near 11×14 / letter family |
| 1.5 | 1.5 | 4×6, 8×12, 24×36 |

**Rule:** subject first → pick the rectangle that *fits* it → only then draw/load the armature. Platform may force the crop (YouTube 16:9); then pick the root that matches *that* crop.

## Basic armature — 30-second build

1. Draw both **main diagonals**.  
2. Drop **reciprocals** (90° to a diagonal from corners).  
3. Mark **eyes**.  
4. Optional: H/V through eyes.  
5. Put the **hero** on a strong line or eye; put support on related lines (echo).  
6. Treat empty space as a shape.

**Most work stops here.** Add MAD/themes only when the frame has multiple zones.

## MAD vs theme vs overlap (when to use which)

| Tool | Plain definition | Use when |
|------|------------------|----------|
| **Basic armature** | Diagonals + reciprocals + eyes | Almost always |
| **MAD** | Smaller armatures inside major sub-areas | Title + face + object in one thumb |
| **Theme of N** | Mother split into N related modules | Sections, panels, repeated beats |
| **Overlapping roots** | Lawful slide of roots for custom outer size | Special canvas sizes, multi-figure art |
| **Phi / Ghyka packs** | Phi-family variants in the PNG set | Organic / human / nature-led pieces (grids only) |

---

## Better than rule of thirds

| ROT habit | DS approach |
|-----------|-------------|
| Same four “power points” every time | Many eyes + either diagonal |
| Flat horizontal thirds | Diagonals give energy and depth cues |
| Everything looks like stock YouTube | Change **theme**, **diagonal**, horizon, negative space |
| Padding by eye | Reciprocals create *related* margins |

Still keep balance, breathing room, and clear figure-ground.

## 15-second workflow

```text
1. Lock delivery crop (16:9, 9:16, 1:1, page…)
2. Match root/phi/1.5 table
3. Open matching BLACK PNG (or build basic armature)
4. Place hero on line/eye; support on echoes
5. MAD only if multi-zone
6. Vary theme from last piece
7. Write grid filename into visual-direction.md
```
