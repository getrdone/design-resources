# Materials mood standard (first-batch consistency)

Approved look = photoreal close-up **material still-lifes** (velvet, silk, metal, acrylic, stone), product/swatch photography.

Canonical references (do not invent a new layout):
- antichrist--materials-mood--01.png
- neon-cyber--materials-mood--01.png
- lux-red / royal-amethyst / gilded-dune / mono-neutral materials moods

Never ship: text titles, hex strips, collage panels, people/figures, narrative prophecy boards, UI screens.

Every theme needs:
1. MATERIALS.txt (mood, surfaces, light, avoids, recreate prompt seed, canonical path)
2. `{theme}--materials-mood--01.png` in `# materials/` gallery
3. copies under `# materials/{theme}/` and `themes/{theme}/materials/`
4. Generate with 1–2 first-batch reference images + recreate seed

Skill: Color theme materials mood (`color-theme-materials-mood`)
