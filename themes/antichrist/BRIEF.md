# Antichrist theme brief

## Palette constraints
- **purple** — deep imperial / amethyst (`#4A0E4E`)
- **scarlet** — blood / flame red (`#9B1B1E`)
- **pearl** — off-white luminous (`#F5F0E8`)
- **gold** — metallic warm gold (`#C9A227`)
- **ink** — near-black grounding (`#140A12`)

## Hard rule
**NO blues / teals / cyan.** Reject any reference or generated asset with strong blue among top colors or mean hue in the blue range.

## Folders
- `references/` — filtered source stills (no blue)
- `palettes/` — palette JSON / CSS / swatches
- `generated/` — parent-agent generated images

## Naming
Use kebab-case theme ids.
