# Materials gallery

Sorts first as `# materials`. One place to browse every theme materials mood board.

## Rule for future themes / imports
Whenever a new color theme is created or downloaded and sorted into this library, **always** add its materials mood image here as:

`{theme}--materials-mood--01.png`

Also keep the per-theme copy + `MATERIALS.txt` under `# materials/{theme}/` and under the pack folder:
- idea libraries: `idea-generators/{library}/materials/`
- named themes: `color-themes/{theme}/materials/`
- Pictures working set: `{name}/materials/`

Do not leave a new theme without a top-level gallery entry.
